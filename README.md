## 一、部署方式（任选其一）

### 方式 A：拖拽部署（最简单）
1. 打开 https://vercel.com/new
2. 将本文件夹整体拖入页面，或用 "Deploy" 上传
3. Vercel 自动识别为静态站点并发布，几秒后给出访问地址

### 方式 B：CLI 部署
```bash
npm i -g vercel        # 首次安装
cd <本文件夹>
vercel                 # 预览部署
vercel --prod          # 正式部署
```

### 方式 C：Git 仓库自动部署
1. 将本文件夹推送到 GitHub / GitLab 仓库
2. 在 Vercel 中 "Import Project" 选择该仓库
3. Framework Preset 选 **Other**（无需 build 命令、无需 output 目录）
4. 部署完成后每次 push 自动更新

> 部署后首页 `index.html` 即 SMT 工作台（角色化 KPI + 待办），所有功能从左侧导航进入。原介绍页已移除（v8.2）。

## 三、范围与原则

- **严格一期**：仅实现合同附件一《项目功能范围与交付清单》范围内功能。
- **超范围项**：ECN 批量联动、品质/RoHS 联动、PO→工单 MES 反查、生产报表 OCR、RPA 外挂 run ERP、7–8 网站实时抓取、客户自助门户、高级 APS、SN 级追溯等，统一放在 `phase2.html` 标注『待商务确认』，**不在本期实现**。
- **诚实交互**：所有 AI 输出为辅助建议，需经"人工确认 → 人工修正 → 记录"闭环后生效；导出走真实文件下载（CSV / 浏览器打印 PDF），不做假"已发送/已生成"。

## 四、数据说明

原型内所有数据（料号、MPN、供应商、价格、ETA、对账金额等）均为演示样例，非真实业务数据。系统运营方为乾创电子（苏州），样例下游客户为旭创/联创科技，平台供应商品牌为硬禾科技。

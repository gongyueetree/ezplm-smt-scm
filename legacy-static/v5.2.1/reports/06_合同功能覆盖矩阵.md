# 报告 6 · 合同功能覆盖矩阵（附件一 Phase 1）

✓ = 原型已呈现页面/流程；所有 AI 输出均含人工确认闭环；ERP 回写均含替代路径。

| 合同模块 | 页面 | 覆盖要点 | 状态 |
|---|---|---|---|
| 1. 基础平台 | dashboard / master-data / settings / integration | 登录·角色权限·操作日志；客户/供应商/物料/MPN/料号/库存/OPO/ETA/PO/工单主数据；Excel/CSV 导入导出；ERP/MES 五通道占位 | ✓ |
| 2. BOM 智能处理 | bom-process | 标准/非模板 BOM、无 MPN 匹配、规则优先级、候选 MPN、OCR、人工确认修正留痕、导出 | ✓ |
| 3. 智能报价 | quote | 分类算点、A/B/C 模式、折扣模拟、报价预览、审批、Excel/PDF、报价历史可追溯 | ✓ |
| 4. 物料报价与采购协同 | material-quote | 固定模板、PM 上传、GTB 计算、采购填价、低价/阈值提醒、重传/PM 修正、主管审批、结果表 | ✓ |
| 5. 采购助手 | procurement | 供应商/MOQ/SPQ/单价/LeadTime、选商带出、Excel 批量上传与冲突处理、历史低价、呆滞提醒、辅助表导出 | ✓ |
| 6. 多源比价与替代料 | price-compare | 模板上传、人工/Excel/已授权 API 录入多平台价格库存DC、最低价标识、比价报表、趋势、EOL 候选替代（人工确认）；实时爬虫为二期 | ✓ |
| 7. OPO 交期协同 | opo / supplier | 导入、按供应商待回复、双周（14 天）模拟催复、门户/Excel 回填、自动匹配、差异/未回复/异常、导出供 ERP 导入 | ✓ |
| 8. 物料追溯 | trace | 料→客户 PO/工单、工单→采购 PO、采购 PO→工单；依赖 ERP/MES 完整性提示与断点标注；非 SN 级 | ✓ |
| 9. 缺料分析与 Call 料表 | shortage | 缺料单导入、ETA 齐料计算、按工单基础模拟、匹配供应商/数量/ETA、Call 料表、邮件内容 | ✓ |
| 10. AR/AP 对账辅助 | ar-ap | 客户/供应商对账单上传、字段匹配、AR/AP 建议清单、待办/导出；不直接生成 ERP 凭证 | ✓ |
| 11. 计划辅助 | planning | BOM+标准工时计算、工时报表、人工修改确认、基础排产建议（齐料/工时/工序/优先级）；非高级 APS | ✓ |

## 端到端 Demo（UAT 场景）
1. BOM 上传→AI 匹配→人工确认→导出标准 BOM（bom-process）
2. BOM→报价规则→折扣模拟→审批→Excel/PDF（quote）
3. PM 物料报价需求→采购填价→低价提醒→PM 确认→主管审批→结果表（material-quote）
4. OPO 导入→供应商回复→匹配→异常清单→导出（opo/supplier）
5. 缺料导入→ETA 齐料→Call 料表→供应商邮件（shortage）
6. 客户/供应商对账上传→字段匹配→AR/AP 建议清单（ar-ap）
7. 一颗料/工单/采购 PO 基础追溯（trace）

> 说明：覆盖指"原型页面/流程已呈现并含示例数据与 Demo"，非"后端已全部实现"。后端实现清单见报告 11。

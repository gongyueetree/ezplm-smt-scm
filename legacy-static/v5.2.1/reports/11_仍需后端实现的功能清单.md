# 报告 11 · 仍需后端实现的功能清单

原型已确认页面/字段/流程/范围；以下能力须由真实后端工程实现（NestJS + Prisma + PostgreSQL）。

## 1. 基础平台
- 账号登录鉴权、角色权限（RBAC）真实落库与会话；操作日志持久化与导出。
- 主数据（客户/供应商/物料/MPN/料号/库存/OPO/PO/工单）真实 CRUD 与租户隔离。
- Excel/CSV 导入导出的后端解析与按模板生成 **XLSX**。

## 2. BOM 智能处理
- 非模板→标准模板转换；无 MPN 匹配（描述/规格/封装/客户料号/内部料号/疑似 MPN）算法与规则优先级引擎。
- 图片/截图/扫描件 **OCR** 服务接入；候选 MPN 推荐与置信度。
- 人工修正结果落库并回流模型校准。

## 3. 智能报价
- 分类算点规则引擎、A/B/C 模式与折扣计算后端化；审批流引擎；审批后真实 **PDF** 渲染。
- 报价历史版本与追溯存储。

## 4. 物料报价协同
- Going to Buy 计算（需求−库存−在途，MOQ/SPQ 圆整）；历史最低价/阈值校验数据源。
- 多角色填报、重传、修正、审批状态机与留痕。

## 5. 采购助手
- 供应商-物料预设（MOQ/SPQ/单价/LeadTime）库；Excel 批量上传冲突合并策略后端实现。
- 历史最低价与内部呆滞料数据源。

## 6. 多源比价与替代料
- 多平台价格/库存/DC 数据：人工录入 + Excel 导入 + **已授权 API**（实时爬虫为二期）。
- 历史报价趋势存储；EOL 候选替代建议数据库与规则。

## 7. OPO 交期协同
- OPO 导入（ERP/中间表/Excel）；双周（14 天）调度真实触发；供应商门户与 Excel 回填匹配引擎。
- 差异/未回复/异常报表生成；导出 ERP 可导入格式，接口可用时回写。
- **真实邮件发送**（依赖甲方邮件账号与 SMTP/API 授权）。

## 8. 物料追溯
- 基于 ERP/MES 的 PO/工单/领料/出入库/批次链路查询；断点检测与人工补全闭环。

## 9. 缺料分析与 Call 料表
- 缺料单解析、ETA 齐料计算、按工单基础模拟；Call 料表生成与邮件内容/发送。

## 10. AR/AP 对账
- 对账单上传解析、字段匹配引擎、AR/AP 建议清单生成（不直接生成 ERP 凭证）。

## 11. 计划辅助
- 标准工时规则库与工时计算服务；基础排产建议（齐料/工时/工序/优先级）。

## 12. 系统集成
- API / 中间表 / 数据库视图 / Excel / RPA 五通道真实实现与字段映射冻结；同步调度、失败重试、待办生成。
- 回写优先级：Excel 导出 → 中间表 → RPA → API。

# 报告 5 · 角色与权限矩阵

角色模型以 `settings.html` 为唯一基准，共 5 个角色，审批链不再出现模型外审批人。

| 角色 | 可见模块（摘要） | 关键权限 | 审批职责 |
|---|---|---|---|
| **PM** | 工作台 / BOM 智能处理 / 智能报价 / 物料报价协同 / 物料追溯 | 上传 BOM 与报价需求、人工确认 AI 输出、确认价格、查看结果表 | 各流程**发起人** |
| **采购** | 采购助手 / 多源比价 / OPO 交期协同 / 缺料 / AR-AP(AP) | 填价、低价提醒确认、供应商条件维护、催办、Call 料 | — |
| **计划** | 计划辅助 / 缺料 / 工单数据 | 工时人工确认、基础排产建议确认 | — |
| **管理人员** | 全部模块 | 参数配置、日志审计、报表 | 各流程**审批人**（报价、物料报价等） |
| **供应商** | 仅 OPO 轻量回复门户 | ETA 回填、Excel 上传、查看自身状态 | — |

## 审批链（统一后）
- 智能报价：PM 发起 → 管理人员审批（毛利低于红线时由管理人员重点审批）。
- 物料报价协同：PM 上传需求 → 采购填价 → PM 确认 → 管理人员（主管）审批 → 下载结果表。
- 计划辅助：计划员确认工时与排产建议。

## 变更说明
- V3 中报价流程出现"销售主管 / 总经理"两个不在角色模型中的审批人，本轮已全部移除并统一为"管理人员审批"。
- 如客户确需独立的"报价主管/总经理"角色，应在角色管理页正式新增、明确权限、增加演示账号、并在审批流程配置中可配置启用（本期未默认引入）。

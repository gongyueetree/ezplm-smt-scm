REST API

GET/api/v1/integration/channels 五通道状态
PUT/api/v1/integration/channels/:type/config 通道配置（连接串/目录/调度）
POST/api/v1/integration/channels/:type/test 连接测试
GET/api/v1/integration/mappings 字段映射（ERP 表/视图 ↔ ezPLM 实体）
GET/api/v1/integration/sync-logs 同步日志与失败重试

🔌 API 接口

REST/WebService 直连 ERP·MES 开放接口。是否可用、接口方式与字段范围待甲方 IT 确认；接口不可用时改走中间表/视图/Excel/RPA。本通道为示例配置。
🗄️ 中间表
可选 · 待联调
建议在客户数据库建 EZ_SYNC_* 交换表：ezPLM 写入待回写数据，ERP 端定时读取。需 DBA 授权；调度策略与表结构待联调确认。替代：无库权限 → 改走 Excel。
👁️ 数据库视图
可选 · 待授权（只读）
建议 DBA 授权只读视图 V_EZ_STOCK / V_EZ_PO / V_EZ_WO 拉取库存、PO、工单，不写客户库。需 DBA 授权确认。替代：无视图权限 → 改走 Excel。
📊 Excel 导入导出
可选 · 兜底通道
所有模块均提供固定模板导入与 ERP 可导入格式导出（OPO 差异表、Call 料表、AR/AP 建议清单等）。无接口依赖，作为兜底通道，无论 API/中间表是否可用均可使用。
🤖 RPA 机器人
可选 · 待确认
对无法开接口又不允许动库的场景：RPA 模拟人工把 ezPLM 导出文件录入 ERP 界面（示例：OPO 交期回写采购订单）。是否采用待客户确认；失败转人工待办。

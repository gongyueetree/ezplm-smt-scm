REST API

POST/api/v1/boms/import 标准/非模板 Excel
POST/api/v1/boms/ocr 图片/截图/扫描件 → 基础表格
POST/api/v1/boms/:id/match body: 规则优先级数组
PUT/api/v1/boms/:id/lines/:ln/confirm 人工确认/修正，写修正日志
GET/api/v1/boms/:id/export?format=xlsx

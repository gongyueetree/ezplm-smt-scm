## 二、需要客户拍板的业务规则

### O7. 正式 BOM 内部料号匹配失败时怎么办 🔴

客户答:「正式 BOM 必须关联客户编码,且要优先匹配系统内部料号」。
但**没说匹配不上时怎么办**。请选:

- [ ] A. **阻止转换** —— 一行匹配不上就不许转
- [ ] B. **允许转换,标记「待补内部料号」** —— 量产前必须补齐(**当前实现取此项的折中**)
- [ ] ~~C. 自动建料~~ —— **我们不会做**。ezPLM 是物料主数据唯一真源,
      导入几次就长出一堆同名料,是把主数据搞烂最快的方式

**当前实现**:允许转换,但必须由发起人**显式确认**,未匹配行标记「待补内部料号」
并计入台账 KPI。若客户选 A,改 `checkConvertToProduction` 里一个分支即可。

### O8. 品质模块要不要独立角色 🟡

客户答:质量事件由**品质**录入,但目前系统里没有 QUALITY 角色。

- [ ] A. 用**权限**即可(`quality.view` / `quality.create` / `quality.manage`),
      先给管理层,再按人授予(**我们推荐**,不动 Role 枚举)
- [ ] B. 新增独立角色 QUALITY

**影响**:B 会改动 RBAC 的角色枚举,牵连菜单、工作台、数据范围与既有测试。
A 能达到同样效果且改动面小得多。

### O9. MES 厂商 / API / SN 结构 🟢

客户答:「最好 SN 级别,但 SN 需要和 MES 关联,请确认是否可以达成」。

**我方答复**:本系统没有 MES,也**不产生 SN**。SN 级追溯的前提是贵司有 MES
或产线能产出 SN 与批次的绑定记录。

- 贵司目前有 MES 吗?[ ] 有(厂商/型号:______)[ ] 无 [ ] 在建
- 若有:SN 的编码规则、能否按工单批量导出 SN ↔ 批次对应关系

**若无 MES,SN 级追溯无法实现** —— 这不是排期问题,是没有数据来源。
PR-E6 会把数据模型做成 SN-ready(`MesTraceProvider` 默认 `NOT_CONFIGURED`),
界面明写「当前粒度:批次级;SN 级:MES 接口待接入」,**绝不生成虚构 SN**。

### O11. Gerber 上传卡死的现场信息 🔴

客户原话:「gerber 无固定大小。**无法将 gerber 作为附件传入,出现死机情况**」。

请提供:

- 卡死时文件多大?(量级即可:50MB?200MB?)
- 是**页面无响应**,还是整个浏览器/电脑卡死?
- 浏览器与版本
- 文件是 `.zip` 还是一堆散文件?
- 最好能给 1–2 份**真实的失败样例**(可脱敏)

**审计已有明确嫌疑**:`app/api/rfq/[id]/attachments/route.ts` 里
`await req.formData()` 会**先把所有文件整个缓冲进内存**,之后才检查 20MB 上限——
传一个 200MB 的包,系统会先吃下 200MB 再告诉你"超过 20MB"。
加上没有上传进度、没有取消,正常的大文件上传在界面上也表现为"卡死"。
PR-E1b 会改这条链路,但**仍需真实样例才能确认就是这一条**。

## 二、先理解三条设计原则

这三条决定了你在界面上看到的很多"奇怪"措辞。**它们是刻意的,不是缺陷。**

### 原则一:不知道就是不知道,不会假装

系统区分三种状态,绝不混为一谈:

| 显示 | 含义 |
|---|---|
| 具体数值 | 有真实数据 |
| **未知 / 未标注 / 数据源未返回** | 确实拿不到,**不等于 0,也不等于没有** |
| **0 / 无** | 确实是 0 |

举例:某颗料库存显示「未知」,意思是外部数据源没返回库存,**不是没货**。
把未知当成 0,采购会误判成缺料;当成有货,又会漏采。所以系统坚持把它单列出来。

### 原则二:算钱的事只由确定性函数做,AI 只出建议

所有价格、GTB、Markup、PPV、人工费、总价,一律由固定算法算出,**AI 不参与任何数值计算**。

AI 能做的是:从规格书里提参数、建议物料分类、建议替代料、生成邮件草稿、汇总影响面。
凡是 AI 给的东西,界面上都标着紫色「Agent」标记,**必须你确认后才生效**。

### 原则三:本系统不是 ERP,不会替你在 ERP 里做事

本系统是 **RFQ / 报价 / 采购比价 / 交期协同** 的真源;
**ERP 才是下单执行、库存过账、出货的真源。**

所以你会看到:

- 采购订单最终状态是「**已审批 · 待 ERP 录入**」,而不是「已下单」;
- 导出 ERP 模板后显示「**已导出 ERP 模板**」,并注明「导出不代表 ERP 已接单」;
- 隔离批次时显示「**本系统已登记**」「ERP 回写待执行」「MES 联动未接入」,
  而不是笼统一句「已冻结」。

## 四、报价与客户(PM)

### 4.1 RFQ 询价 `/rfq`

1. **新建 RFQ** → 填客户、项目、需求日期
2. **上传附件** —— 可传多个:BOM、Gerber、工艺说明都行
3. 客户不报价时:**关闭 RFQ 必须填原因**,关闭后进入终态不可再改

### 4.2 报价管理 `/quotes`

**创建报价的两条路**:

- 从 RFQ 新建
- 从 BOM 一键转化:BOM 版本页 → 「**生成报价单**」(客户与 RFQ 自动带入,不用重填)

**报价行包含**:报价 MFG/MPN、采购成本、Markup 比例、报价价格、替代料 MFG/MPN、物料类别。
右侧汇总显示:物料成本、物料最终报价、**PPV**、人工费、总价。

**必须逐行确认物料分类** —— 分类没全部确认,提交按钮点不动。这是刻意的:分类影响 Markup。

**状态流转**:

```
草稿 → 待审批 → 已批准 / 已退回 / 已过期
```

- 提交时**冻结快照**:此后改任何参数都不影响已提交的版本
- 退回**必须写原因**
- **已批准的版本不可覆盖**,要改就新建 Revision
- 导出与打印**只用快照**,不会因为你后来改了参数而变

**生成正式报价单**:报价详情页 → 打印视图 → 浏览器「打印 → 另存为 PDF」。
版式是固定模板(甲方 / 单号 / 报价日期 / 有效期 / 明细 / 分类汇总 / 商务条款 / 双方签署栏),
**不是截屏系统界面**。

> ⚠️ 服务端直接生成 PDF(用于邮件附件、批量导出)尚未做,当前需经浏览器另存。

### 4.3 报价模板与客户分级 `/settings/quote-templates`

按 A/B/C 客户等级预设不同的 Markup 档位与人工费模板。
页面下方的**推演表**会显示:每个客户当前等级 → 命中哪套模板 → 为什么。

Markup 留空显示「**未维护**」而不是 0 —— 未维护和不加价是两回事。

## 五、BOM 与物料(工程 / PM)

### 5.1 BOM 管理 `/bom`

顶部五张卡片,**点任意一张即按该指标自动筛选**,不用二次筛:

| 卡片 | 含义 |
|---|---|
| BOM 总数 | 全部 |
| **EOL 物料占用 BOM** | 含停产料的 BOM。注意:生命周期未知**不算** EOL,未知数单独显示 |
| **超期未更新 BOM** | 默认超过 90 天。此口径**未经业务确认**,可在筛选栏改 |
| 需人工确认物料 | 匹配未确认的行数 |
| 未识别物料 | 完全没有候选的行数 |

支持客户 + 时间组合筛选,以及**批量导出清单 / 批量导出异常物料**。

### 5.2 BOM 导入 `/bom/import`

支持格式:**Excel / CSV / PDF / 图片**。

- **PDF 有文本层**时走确定性几何重建,精度高
- **扫描件与图片**才调用 AI 转写。AI 只负责"把表格逐字抄下来",**不猜型号、不补全、不做单位换算**;数量仍由系统重新解析
- 支持一次传**多个文件**
- 列名自动识别(位号 / Reference / Qty / Value / MPN / 厂商 / 封装 等常见写法)
- **坏行逐行报错并带行号**,不会静默丢掉
- 大 BOM(>50 个唯一型号)自动分批导入并显示进度

导入完成后可直接跳转版本比对。所有导入记录留在 **导入历史** `/bom/imports`。

### 5.3 匹配确认

匹配管线按此顺序出候选:客户料号 → 内部料号 → 精确 MPN → 制造商+MPN → 描述 → ezPLM → DigiKey/Mouser。

**候选只是建议,必须逐行人工确认**才会写入决定。未确认的行不会进报价。

### 5.4 版本比对 `/bom/compare`

选两个版本 → 显示新增 / 删除 / 数量变更 / 料号变更。
点「保存本次比对」进台账,以后一键回到同一对版本,不用每次重选。

### 5.5 物料查询 `/materials`

左侧按分类树筛选(一级大类 + 二级细分),支持自定义标签(如「国产替代物料」「关键 A 类客户物料」)。

列表含 SMT 工艺字段:**MSL 湿敏等级 / 包装规格 / 盘装数量**。

**新增物料**(工程 / 管理层可见):

1. 点右上角「**+ 新增物料**」
2. 填内部料号与 MPN → 系统**自动查重**:同租户重复料号直接拒绝;疑似重复(同 MPN / 别名 / 客户料号)会列出候选让你选:用已有物料 / 建客户料号映射 / 仍然新建(**必须填原因**)
3. **从 ezPLM 引用**:输入 MPN 点引用,能自动带回描述、封装、参数、生命周期,不用逐字段手打
4. 选分类后**动态加载该类的参数模板**(IC 和电阻要填的参数不一样)
5. 上传规格书可让 AI 提参数 —— 提取结果标着**来源与置信度**,且**绝不覆盖你已填的值**
6. 可「保存草稿」(允许缺字段)或「创建物料」(执行完整校验)

物料来源分四种,界面上都有标注:`ezPLM 缓存` / `本地自建` / `批量导入` / `ERP 同步`。

**批量导入**:适合从旧系统迁移,粘贴或上传表格即可,同样逐行校验。

### 5.6 物料详情页

九个区块:基本信息(多源合并,每个字段标来源)、规格参数、**原理图符号与 PCB 封装在线预览**(可缩放拖动)、**3D 模型**、分销商实时价格与库存、数据手册与库文件、**替代料**、供应与库存、参考设计。

### 5.7 替代料

两个入口:

- 物料详情页「⑦ 替代料」→「**查找替代料**」(快速看一眼)
- `/materials/alternates`(可调参数优先级,精细控制)

**四维评分**:技术兼容 / 证据覆盖 / 来源可信 / 结论可信。

五种替代模式:Pin-to-Pin / 封装兼容 / 功能替代 / 国产替代 / 低成本。

> ⚠️ **Pin-to-Pin 未经人工核对引脚时,系统永远不会判"可直接替换"**,并会显式警示。

结果可勾选进「候选清单」,保存的是**勾选当时的评分快照**,刷新后仍在。
**勾选 ≠ 替代关系成立**,正式关系需另行确认。

### 5.8 合规到期看板 `/materials/compliance`

管控 RoHS 报告 / REACH 报告 / COC 三类文档的有效期。

两条口径要记住:

- **「未标注有效期」按告警处理** —— 状态不可知不等于合规
- **「缺少该类文档」与「文档已过期」是两件事**,分两张表统计

## 六、采购协同(采购)

### 6.1 采购 RFQ 比价 `/procurement/rfq`

1. 选 BOM 版本创建比价单
2. 「查询 DigiKey / Mouser」拉取多源报价(分批进行,有进度条)
3. 也可**导入线下供应商报价**(Excel/CSV,自动识别 MPN/单价/币种/MOQ/SPQ/交期)

**比价规则**:

- 同一颗料的报价放在一起比
- **同号异厂、异币种、圆整后取不到阶梯价**的报价会被**标注排除原因**,而不是静默丢掉
- **系统不做汇率换算** —— 异币种一律标为不可比
- 「推荐」与「最低价」**分别标识**(推荐综合价格/库存/交期/生命周期/供应商优先级)
- **拒绝推荐必须写理由**

**异常闭环**(重要):

- 填价时系统**固化"原始异常集合"**
- 处理结论**默认为空,必须逐项人工选**(接受 / 重新询价 / 换货源 / 调价)
- **换货源必须记录**新供应商、币种、MOQ、SPQ、交期、报价时间
- 调价或换货源后**新价格要重新过一遍校验**
- **所有原始异常行都处理完**才能反馈 PM —— 不是"现在不超线了就算过"

### 6.2 采购申请单 `/procurement/request`

PM 或采购发起。**GTB 试算会展示逐步计算过程**:

```
GTB = ceil(需求 × (1 + 损耗率)) − 库存 − 在途
      → 不低于 MOQ → 按 SPQ 向上圆整
```

> ⚠️ 损耗率默认 0,标注「**待甲方确认**」。

同 MPN 有呆滞库存时会提示。

### 6.3 采购订单 `/procurement/orders`

**批量录入**:从 Excel 整块复制粘贴即可,列顺序随意,坏行逐行报错。
缺列**留空而不是填 0** —— 单价填 0 会被复核误读成免费。

**价格复核**:自动与**已批准/已导出**单据的历史成交价对比。

- 首次采购如实标「**首次采购,不可比**」,**不显示为价格正常**
- 涨幅超线(默认 10%)判为异常,**未处理不得提交复核**

**两级审批**:

```
草稿 → 待价格复核 → 待审批 → 已审批·待 ERP 录入 → 已导出 ERP 模板
```

- 进入复核后**行项冻结**,不可再改价
- 退回**必须填原因**
- **已批准不可回到可编辑态**
- 终审通过可一并生成在途行(OPO)

**导出 ERP 批量下单模板**:产出可导入 ERP 的 xlsx。
模板里也写明「本表由 ezPLM SMT 生成,生成不代表 ERP 已接单」。

### 6.4 供应商与采购策略 `/procurement/suppliers`

维护供应商的 MOQ / SPQ / 交期 / 多阶价格,以及采购阈值(价格线、交期线、涨幅告警线)。

> ⚠️ 阈值未勾选「已业务确认」时,系统会持续标注「**非正式风控**」。

### 6.5 供应商协同 `/suppliers/collab`

- 批量生成订单通知**邮件草稿**
- 供应商建档**邀请邮件草稿**
- 接单回执登记

> ⚠️ **邮件通道尚未接入**。以上全部是**草稿/预览**形态,系统**不会真的发出任何邮件**,
> 界面上不会出现「已发送」字样。你需要复制草稿内容自行发送。

### 6.6 OPO 交期协同 `/suppliers/opo`

在途订单的行级台账。KPI、未回复表、差异表、异常清单**全部由同一份行数据派生**。

- 记录供应商回复:ETA / 数量 / 备注 / 回复来源
- **催办**:每日扫描,提前 4 天提醒
- **ERP 交期回写模板**可导出

> ⚠️ 催办目前**只生成记录(状态 PENDING),不发送真实邮件**。

## 七、履约与对账

### 7.1 AR/AP 对账 `/reconciliation`

按角色分两个 Tab:**AR(应收,对客户,PM 侧)** / **AP(应付,对供应商,采购侧)**。

流程:创建对账单 → 粘贴对方对账单 → 选我方基准 → 执行匹配 → 逐项处理差异。

**我方基准两条来源**:

- **本系统派生**:AP 用已批准 PO 行,AR 用已批准报价行
- **上传 ERP 导出明细**

> ⚠️ **本系统没有出货/入库/发票数据**(那是 ERP 的范围),所以基准只能是上面两种,
> 界面上会明确标注本次用的是哪一种。

**差异自动识别**七种判定:一致 / 数量差异 / 单价差异 / 金额差异 / 币种不一致 / 仅对方有 / 仅我方有。

> 💡 特别注意:**金额对得上但数量与单价对不上**(两者互相抵消)时,系统**判为差异而不是一致**
> —— 这是最危险的一类,看着没事其实两边记的不是同一件事。

**账龄分析**:未到期 / 0-30 / 31-60 / 61-90 / 90+ / **到期日未知**。
「到期日未知」**单列一档,绝不并入 0-30 天**。

### 7.2 缺料分析 `/shortage` 与齐料检查 `/kitting`

按台数核算需求,**数据未知的行排在最前**,不当作有货。

### 7.3 库存总览 `/inventory`

支持按客户 / 日期筛选。含呆滞分析与 DC 库龄。
**DC 未知的单列**,不并入最新库龄区间。

### 7.4 损耗报告 `/scrap`

导入损耗数据 → 按 MPN / 客户 / 原因分析 → 按客户模板导出。

损耗率分母为 0 或未知时显示「**不可计算**」,不显示 0%。

## 八、批次级全链路追溯 `/traceability`

### 8.1 当前能力边界(务必先读)

> **当前追溯粒度:批次级**
> **SN 级追溯:待 MES / SN 数据接入**
>
> 数据靠**导入**(三张模板)或 ERP 同步,**无 MES 联动**。

### 8.2 数据从哪来

三张标准模板,可下载空表:

| 模板 | 作用 |
|---|---|
| **收料批次** | PO / 供应商批次 → 内部批次 |
| **工单用料** | 内部批次 → 工单(**全链路最关键的一跳,缺了整条链就断**) |
| **出货关系** | 成品批次 → 工单 / 客户 / 出货单 |

导入会保存原始文件、逐行校验、支持幂等重复导入、可撤销未被引用的错误导入。

### 8.3 查询与追溯

支持按内部料号 / MPN / 物料批次 / 供应商批次 / PO / 工单 / 成品批次 / 客户 PO / 客户 / 出货单查询。

- **正向追溯**:这批料流到哪去了
- **反向追溯**:这批货是用什么料做的

结果同时提供关系图、表格、时间线,可导出报告。

### 8.4 影响范围分析(Blast Radius)

从异常批次出发,五层展开:异常源 → 关联批次 → 工单 → 成品批次 → 客户与出货。

统计:受影响批次 / 工单 / 成品批次 / 出货数 / 客户数 / 仍在库 / 在制 / 已出货数量。

> 💡 **最重要的一条**:某一段没有数据时,系统显示
> 「**未发现工单用料记录 —— 这不代表没有影响,而是这一段数据没有**」
> 并列出可能原因(ERP/MES 未同步 / 模板未导入 / 尚未投产)。
>
> **数据缺失绝不会被显示成"零影响"。**

### 8.5 冻结与隔离

可提出的动作:冻结库存批次 / 暂停工单 / 标记待复检 / 创建 RMA 草稿 / 供应商通知草稿 / 客户通知草稿 / CAPA 任务 / 召回评估 / 导出隔离清单。

**每个动作都有明确的执行状态**:

```
建议 → 待审批 → 本系统已登记 → 待外部系统执行 → 外部系统已确认 / 执行失败
```

> ⚠️ 未接 ERP/MES 时,状态最多到「**本系统已登记**」与「**待外部系统执行**」。
> **系统绝不会显示「ERP 已冻结」或「设备已停机」。**

**提议与批准分离**:提议人 ≠ 批准人,无审批权限的人只能提议。

### 8.6 Trace Agent

可汇总影响范围、解释关系、提出建议动作、生成通知草稿与 8D/CAPA 草稿,并**展示它用了哪些证据**。

> ⚠️ Agent **绝不会自动**冻结库存、停止工单、通知客户或供应商、发起召回、修改 ERP/MES 状态。
> 所有正式动作必须人工审批。

### 8.7 供应商看到的是受限视图

供应商登录后**只能看到自己的** PO 与批次,且**看不到下游**(自己的料流到哪个工单、做成什么、卖给谁)——
这些是本厂与其客户之间的商业信息。

页面会说明这是受限视图,而不是让供应商误以为"下游没有影响"。

## 九、系统设置(管理层)

### 9.1 权限配置 `/settings/permissions`

三层叠加,后者覆盖前者:

```
角色默认权限  →  租户级额外授予  →  用户级授予 / 回收
```

- **角色默认权限只读**(显示绿色「默认」徽标)—— 改它等于改产品设计,应走代码评审
- 租户级:给某个角色额外授予某项权限
- 用户级:对单个用户授予或回收

**生效权限推演**是这个页面最有用的部分:选一个用户,逐权限显示「有/无 + 由谁决定 + 完整来源链」,
能直接回答「他为什么有这个权限」。

> ⚠️ 系统**不允许你回收自己的「权限管理」权限** —— 否则将无人能进入此页面。

所有权限变更都写入审计日志。

### 9.2 ERP 同步 `/settings/integrations/erp`

四步向导:连接配置 → 字段映射 → 同步策略 → 预览数据。

**支持的 ERP**:

| 厂商 | 状态 |
|---|---|
| **Excel / CSV** | ✅ **真实可用** —— 无 ERP API 时的兜底通道 |
| **金蝶**(K3 / 云星空 / 星瀚) | 🔶 **真实 Adapter 骨架**,登录端点与字段表已就位,**待真实账套联调** |
| 用友(U8/NC/YonBIP)、SAP、Oracle | 🔶 **接口已定义,待联调** |
| Mock | 演示用,界面标注「示例数据」 |

> ⚠️ **状态显示纪律**:
> - 「**已连接**」**只在真实请求成功后**才会出现;
> - 未配置凭据一律显示「**待联调**」,系统**不会发出任何请求**,也不显示假的绿灯;
> - 未联调的厂商调用时**明确报「尚未联调」**,而不是返回空数据冒充"同步完成 0 条"。

**凭据安全**:AppSecret / Token / 密码**加密存储**,界面只显示掩码(末 4 位),
接口不回传明文,日志与审计不记录密钥。**未配置加密密钥时系统拒绝保存凭据**,不会降级成明文。

**同步流程**:必须**先预览再执行**。预览显示新增 / 更新 / 无变化 / 冲突 / 跳过 / 错误的行级差异。

> ⚠️ **双向同步不会按"最后更新时间"自动覆盖** —— 所有冲突进入**人工处理队列**,
> 可批量接受 ERP 值、批量保留本系统值,或单行人工填值。

**同步日志** `/settings/sync-log`:每次同步的连接、方向、实体、时间、各类计数、触发人、行级结果都可查。

## 十、常见问题

**Q:为什么某颗料的库存显示「未知」?**
A:外部数据源没返回库存数据。**未知不等于没货**。请以 ERP 实际库存为准。

**Q:为什么替代料给了高分,却还提示"需人工核对引脚"?**
A:Pin-to-Pin 模式下,系统不会仅凭参数匹配就判定可直接替换。引脚映射必须人工核对。

**Q:为什么点了"发送邮件"却没收到?**
A:邮件通道**尚未接入**,当前所有邮件都是**草稿/预览**形态。界面上不会出现「已发送」。

**Q:采购订单审批完了,为什么状态不是"已下单"?**
A:本系统不在 ERP 里下单。审批通过 = 「已审批·待 ERP 录入」,导出模板后需人工/RPA 导入 ERP。

**Q:追溯查不到工单,是不是没影响?**
A:**不是。** 页面会明确写「未发现工单用料记录 —— 这不代表没有影响,而是这一段数据没有」,
并列出可能原因。请先确认工单用料模板是否已导入。

**Q:为什么两个数据源的价格差好几倍?**
A:优先怀疑四种情况(而不是直接采信低价):①币种口径不同 ②同号异厂料 ③账户协议价 ④封装/批量不同。
系统**不做汇率换算**,异币种一律标为不可比。

**Q:BOM 导入后有些行没进列表?**
A:看导入结果的**逐行报错**,每条都带原始行号与原因。系统不会静默丢行。

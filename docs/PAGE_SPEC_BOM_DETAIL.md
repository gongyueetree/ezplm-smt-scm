# PAGE SPEC · BOM 详情页(BOM Detail)

来源:`legacy-static/customer-demo/bom-detail.html`(客户测试版)。本规格把该页内容**按范围分层**后交付实现,禁止整页照搬——静态页里混有二期制造工程内容(工艺路线/钢网/治具/Feeder)与已有能力(匹配确认)。

**范围分层约定**
- **T1 标准产品**:本轮实现,面向所有租户;
- **T2 Feature Flag**:本轮实现数据模型与页面,默认关闭,租户开关启用;数据源缺失时显示"数据源待接入"空态;
- **T3 二期/待商务确认**:本轮不做,页面以折叠占位卡呈现,注明"待商务确认",不得放示例数据。

---

## 1. 页面骨架(T1)
路由 `/bom/[bomId]`(版本经 `?v=` 或子路由 `/bom/[bomId]/versions/[versionId]`);统一 PageHeader/Breadcrumb/BackButton(返回 BOM 列表或所属 RFQ,取决于入口);顶部信息条:BOM 名称、客户、产品、当前版本号、版本状态、关联 RFQ/报价、关联 ECN(如有)。

顶部 KPI 条(数据来自既有 BOM 导入/匹配结果,走 `lib/metrics`):总物料数、版本数、已匹配(及匹配率)、需人工确认(置信度 < 阈值)、未识别。**阈值(如 90%)为租户配置,不硬编码**。

---

## 2. 物料明细 Tab(T1,主体)
复用既有 BOMLine + BomMatchCandidate + BomLineDecision,**不新建第二套匹配 UI**。

列:位号(refDes)| 客户描述 | 内部料号 | MPN | 制造商 | 用量 | 库存(经 MasterDataProvider,标注数据更新时间)| 匹配状态 | 操作。
- 匹配状态徽标:已确认 / AI 建议·置信度 xx% / 需人工确认 / 未识别 / 多候选(如 U7 有 3 个内部料号候选时显示"3 候选",点开选择);
- 快速筛选:全部 / 需人工确认 / 未识别 / 有替代;
- 行操作:查看候选、人工确认、指定物料、标记无匹配——全部落 BomLineDecision + AuditLog;
- 行级来源提示:候选来源(客户料号映射/内部料号/MPN/描述/ezPLM/DigiKey/Mouser/人工)与置信度并列显示,**AI 匹配 Agent 编号等营销式标签不进产品**;
- 「一键确认高置信匹配」:对 ≥ 阈值的行批量确认,须弹确认卡片列出条数与阈值,可逐条取消勾选;写入逐行 Decision + 一条批量 AuditLog。这是既有能力的批量入口,不是新逻辑。

静态页里的"图像识别 Agent 从图片/PDF 提取"仅当仓库已有图片/PDF 导入能力时显示来源标记;否则不出现。

---

## 3. 版本 Tab(T1 核心 + T2 图谱)
**T1 版本列表与对比**:版本号、创建人/时间、状态(草稿/已发布/审批中/归档)、变更点数、关联 ECN、关联工单数(经 ERP Provider,缺则"待接入")。版本对比复用既有 `/bom/compare` 能力:对比维度至少物料总数、新增/删除/替换行、EOL 物料数、单板物料成本(取报价/采购成本源,币种标注)、关联 ECN;支持导出差异。**不得新写第二套 diff 逻辑**。

**T2 版本演进图谱(Feature Flag `bom.versionGraph`)**:以现有 BOMVersion 父子关系渲染树/时间线(分支/合并/ECO 分支来源于 ECN Apply to BOM 的回链 ecnId);节点显示版本、日期、状态、工单数、变更点;点击节点跳对比。无复杂图库需求时用简单 SVG/列表树。

---

## 4. 制造工程信息(T2,Feature Flag `bom.manufacturingInfo`)
静态页的四张卡:工艺路线(工序/工作中心/节拍/关键参数)、拼板规格、钢网、工装治具与程序版本。**本轮只做数据模型与只读展示**,不做工艺变更审批、不做参数校验:
- 模型建议:`BomVersionManufacturingInfo`(JSON 或结构化子表,tenant scoped),字段按静态页四卡归类;
- 录入方式:表单维护或 XLSX 导入(复用通用导入框架);
- 关键参数变更"需 PE 审批"属工艺流程,**不实现**,页面注明;
- 数据源为空 → 空态"制造工程信息待录入 / 待 MES 接入"。

---

## 5. SMT 站位贴装料 · Feeder Layout(T3 待商务确认)
依赖机台程序/Feeder/库位扫码(MES/仓储数据),前期范围纪律列为二期。本轮仅折叠占位卡,注明"SMT 站位与 Feeder 排布依赖 MES/仓储数据,待商务确认"。辅料(锡膏/助焊剂等)"不计入 EBOM"的说明可保留为文案。

---

## 6. AVL / 替代料策略(T1 只读 + T3 引擎)
- T1:行内展示既有 PartAlternate 替代关系与替代等级(既有能力),EOL 行显示"有 N 个替代"入口;
- T3:静态页"AVL 规则引擎/5 种替代策略配置页"属二期,占位注明。

---

## 7. 审批与提交流程(T1,复用)
静态页的"BOM 提交确认流程 / 审批历史"复用既有 BOM 版本状态与 AuditLog 时间线组件,不新建流程引擎;"流程模板"字样不出现(无流程引擎)。

---

## 8. 明确不做(本轮)
MES 同步指令、SN 绑定/WIP、Feeder 扫码校验、工艺参数审批、AVL 规则引擎、图像识别导入(除非已有)。

---

## 9. 验收
- 物料明细所有操作均落 Decision + AuditLog,批量确认可逐条取消且有确认卡片;
- 库存列显示数据更新时间与来源,ERP 未配置时显示"待接入"而非 0;
- 版本对比与既有 compare 共用同一 diff 函数(单测证明);
- Feature Flag 关闭时 T2 区块不渲染、不请求;开启且无数据时显示空态;
- 无任何示例/假数据;
- Playwright:进入详情 → 筛选需人工确认 → 单行确认 → 批量确认(取消一条)→ 版本对比导出 → 返回上一层。
